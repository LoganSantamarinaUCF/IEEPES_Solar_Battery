# Solar-Powered Battery Pack ☀️🔋

Welcome to the hardware repository for the **IEEE PES UCF** Solar-Powered Battery Pack project! This repository contains all the KiCad schematic and PCB design files necessary for team collaboration.

---

## 📌 Project Overview

The goal of this project is to design and build a reliable, custom solar-powered battery pack. The system integrates solar energy harvesting, intelligent battery management, and efficient power conversion into a single cohesive hardware design.

### Key Features
* **Solar Panel Input:** Optimized power collection from external solar photovoltaic cells.
* **BQ Battery Management System (BMS):** Texas Instruments BQ-series IC implementation for safe charging, overvoltage/undervoltage protection, and thermal monitoring.
* **Custom Rectifier Circuit:** Designed for efficient power conditioning before reaching the charge controller.
* **Custom PCB:** Fully designed and layout-routed using KiCad.
